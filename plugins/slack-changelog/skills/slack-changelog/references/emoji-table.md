# Emoji table

Indicative, not exhaustive. Pick the shortcode that best matches what the bullet is about, and
never reuse one for two bullets that mean different things in the same post.

| What the bullet is about | Shortcodes |
|---|---|
| New capability, something added | `:new:` `:sparkles:` `:tada:` |
| Bug fix, something that was broken | `:bug:` `:wrench:` `:adhesive_bandage:` |
| Performance, speed | `:zap:` `:rocket:` |
| Login, security, permissions | `:lock:` `:key:` |
| Interface, visual change | `:art:` `:eyes:` |
| Action required from the reader | `:warning:` `:point_right:` `:pushpin:` |
| Data, reporting, traceability | `:clipboard:` `:mag:` `:bar_chart:` |
| Cleanup, removal | `:wastebasket:` `:broom:` |
| Communication, notifications | `:writing_hand:` `:speech_balloon:` |
| Crediting a person or team | `:bust_in_silhouette:` |

If a bullet doesn't fit any row, reread it. A bullet with no natural emoji is usually one that's
still too technical to translate.
